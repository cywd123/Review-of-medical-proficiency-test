# 骨的分类
## 一、 成人骨的总数与特殊归类
成人全身共有 **206块骨**，其中 **6块听小骨** 属于感觉器范畴。

## 二、 按部位分类
骨按所在部位可分为三类，其中颅骨与躯干骨合称**中轴骨**。
1.  **颅骨**：构成颅腔，保护脑等重要器官。
2.  **躯干骨**：包括椎骨、胸骨、肋骨等，构成躯干的支架。
3.  **附肢骨**：连接于中轴骨，分为上肢骨和下肢骨，支撑四肢并参与运动。

## 三、 按形态分类
按形态骨可分为**长骨、短骨、扁骨、不规则骨**四类，各类骨的形态、分布及结构特点各不相同。

| 骨的类型     | 形态特点      | 分布区域         | 特殊结构/功能                                                                                                                                                                |
| :------- | :-------- | :----------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **长骨**   | 长管状，分一体两端 | 四肢           | 1. 体（骨干）：内有髓腔，容纳骨髓；表面有滋养孔，为血管出入通道<br>2. 端（骺）：表面有关节面，参与构成关节<br>3. 干骺端：骨干与骺的相邻部分<br>4. 骺软骨：幼年时干骺端的透明软骨，可增殖骨化使骨加长；成年后骨化遗留**骺线**<br>5. 损伤影响：骺软骨损伤可致骨桥形成，骺板提前闭合，引发肢体短缩或成角畸形 |
| **短骨**   | 形似立方体     | 连结牢固且运动灵活的部位 | 如腕骨、跗骨，多成群分布                                                                                                                                                           |
| **扁骨**   | 呈板状       | 颅腔、胸腔、盆腔壁    | 保护内部脏器，如颅盖骨、肋骨                                                                                                                                                         |
| **不规则骨** | 形状不规则     | 躯干、颅底等部位     | 部分骨内有与外界相通的腔洞，称为**含气骨**，如上颌骨；典型代表为椎骨                                                                                                                                   |

## 四、 特殊类型骨——籽骨
1.  **定义**：位于肌腱内的扁圆形小骨。
2.  **作用**：运动中减少肌腱与骨之间的摩擦，同时改变肌肉牵拉方向。
3.  **人体最大籽骨**：髌骨。

# 骨的构造
骨的基本结构由 **骨质、骨膜和骨髓** 三部分组成，三者协同作用，保障骨的支撑、运动、造血等生理功能。

## 一、 骨质（osseous substance）
由骨组织构成，是骨的主要成分，按结构致密程度分为**骨密质**和**骨松质**两类。

| 类型 | 结构特点 | 分布位置 | 特殊说明 |
| :--- | :--- | :--- | :--- |
| **骨密质** | 结构致密，抗压、抗扭曲能力强 | 骨的表面 | 扁骨的骨密质分**内板**和**外板**，外板厚韧有弹性，内板薄而松脆，颅盖骨骨折多发生于内板 |
| **骨松质** | 呈海绵状，由交织的骨小梁排列而成 | 骨的内部 | 骨小梁排列方向与骨承受的压力、张力方向平行，可增强骨的承重能力<br>扁骨的骨松质位于内、外板之间，称为**板障**，有板障静脉穿行<br>短骨和长骨骨骺的外周为薄层骨密质，内部为大量骨松质 |

## 二、 骨膜（periosteum）
1.  **组成与分布**：主要由纤维结缔组织构成，覆盖于**关节面以外**的骨表面；骨髓腔和骨松质网眼内衬有菲薄的结缔组织膜，称为**骨内膜**。
2.  **结构分层**：骨膜分内、外两层，外层致密，胶原纤维束穿入骨质以固着骨面；内层疏松。
3.  **核心功能**
    - 营养支持：富含神经、血管和淋巴管，为骨组织提供营养。
    - 再生塑形：骨膜内层和骨内膜含有成骨细胞和破骨细胞，可生成新骨质、破坏旧骨质，实现骨的生长与重塑。
    - 感觉传导：丰富的神经末梢可感知外界刺激。
4.  **临床意义**
    - 幼年期骨膜功能活跃，促进骨的生长发育；成年后功能相对静止，维持骨的生理状态。
    - 骨折时，骨膜的成骨功能会重新激活，促进骨折愈合；若骨膜过度剥离或损伤，会导致骨折愈合困难。

## 三、 骨髓（bone marrow）
1.  **分布位置**：充填于骨髓腔和骨松质的间隙内。
2.  **类型与特点**

| 类型 | 颜色与成分 | 功能 | 分布变化 |
| :--- | :--- | :--- | :--- |
| **红骨髓** | 红色，含不同发育阶段的红细胞和幼稚血细胞 | 造血、免疫功能 | 胎儿和幼儿的骨髓全为红骨髓 |
| **黄骨髓** | 黄色，主要由脂肪组织构成 | 失去造血能力 | 5岁以后，长骨骨干内的红骨髓逐渐被脂肪组织替代，转化为黄骨髓 |
3.  **功能代偿**：失血过多或重度贫血时，黄骨髓可转化为红骨髓，恢复造血功能。
4.  **临床应用**：椎骨、髂骨、肋骨、胸骨，以及肱骨、股骨等长骨的**骺内**终身存在红骨髓，临床常选择**髂前上棘**或**髂后上棘**进行骨髓穿刺，检查骨髓象。
