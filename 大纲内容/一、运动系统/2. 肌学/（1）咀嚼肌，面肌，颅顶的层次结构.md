
# 咀嚼肌

咀嚼肌（masticatory muscle）包括咬肌、颞肌、翼内肌和翼外肌 ，分布在颞下颌关节周围，参与咀嚼运动。
1. **咬肌（masseter）**：
    - **起止点**：起自颧弓下缘与内面，肌纤维斜向后下，止于咬肌粗隆。
    - **功能**：收缩时上提下颌骨，还能向前牵引下颌骨。
2. **颞肌（temporalis）**：
    - **起止点**：起于颞窝，肌束呈扇形向下汇聚，经颧弓深面，止于下颌骨的冠突。
    - **功能**：收缩时上提下颌骨，也可向后牵拉下颌骨。
3. **翼内肌（medial pterygoid）**：
    - **起止点**：起自蝶骨的翼突窝，止于下颌角内面的翼肌粗隆。
    - **功能**：收缩时上提下颌骨，并使其向前运动。
4. **翼外肌（lateral pterygoid）**：
    - **起止点**：位于颞下窝内，起自蝶骨大翼下面和翼突外侧面，向后外止于下颌颈。
    - **功能**：两侧同时收缩作张口运动；一侧收缩使下颌骨移向对侧。

# 面肌


面肌为面部扁薄皮肌，位置浅，多起于颅骨不同部位，止于面部皮肤。主要分布于口、眼、鼻等孔裂周围，分环形肌和辐射状肌，可闭合或开大孔裂，还能牵动面部皮肤展现表情，因此又称表情肌。面肌具体分为以下几种：
1. **颅顶肌**：即枕额肌，左右各一，是颅顶部阔而薄的肌。由前、后肌腹及中间的帽状腱膜构成。
    - **额腹**：位于额部皮下，止于眉部皮肤。
    - **枕腹**：位于枕部皮下，起自枕骨，止于帽状腱膜。枕额肌与颅部皮肤、皮下组织紧密结合构成头皮，与深部骨膜以疏松结缔组织相隔。收缩时，枕腹向后牵拉帽状腱膜，额腹提眉并使额部皮肤出现皱纹。
2. **眼轮匝肌**：位于眼裂周围，呈椭圆形，分为眶部、睑部和泪囊部。
    - **睑部**：纤维收缩时眨眼，与眶部纤维共同收缩使眼裂闭合。
    - **泪囊部**：纤维收缩扩大泪囊，使囊内产生负压，利于泪液引流。
3. **口周围肌**：结构高度分化，形成复杂肌群，含环形肌和辐射状肌。
    - **口轮匝肌**：环绕口裂的环形肌，收缩时闭口，并使上、下唇与牙贴紧。
    - **辐射状肌**：位于口唇上、下方，能上提上唇、降下唇或拉口角向上、向下或向外侧。其中较重要的是颊肌，起自面颊深层，止于口角。收缩时使唇、颊贴紧牙齿，助咀嚼和吸吮，还可将口角拉向外侧，与口轮匝肌共同作用可作吹口哨动作。
4. **鼻肌**：为几块不发达的薄扁小肌，分布在鼻孔周围，作用是开大或缩小鼻孔。

# 颅顶

颅顶软组织通常分为**额顶枕区**（经典五层）和**颞区**（层次有差异），其中额顶枕区的前三层紧密结合，合称为**头皮**，以下是详细的层次结构及肌学特点：

### 额顶枕区（由浅入深五层）

1. **皮肤**：厚而致密，富含毛囊、汗腺、皮脂腺；血管丰富，外伤出血多但愈合快；是疖肿、皮脂腺囊肿的好发部位。
2. **浅筋膜（皮下组织）**：由致密结缔组织和脂肪构成，结缔组织形成垂直小梁分隔脂肪，内有丰富血管神经网；感染时渗出物局限，疼痛剧烈；血管断端不易回缩，需加压或缝合止血。
3. **帽状腱膜与额枕肌**：帽状腱膜坚韧，前连额腹（额肌）、后接枕腹（枕肌），两侧变薄续于颞筋膜浅层；额肌收缩可提眉、形成额纹，枕肌收缩可牵引头皮向后；头皮横向裂伤时，此层收缩会使创口明显裂开。
4. **腱膜下疏松结缔组织（腱膜下间隙）**：为疏松的蜂窝组织，范围广（可前达眶部）；移动性大，血肿易扩散至眼睑皮下；有导血管与颅内静脉窦相通，感染可向颅内蔓延，是颅顶的 “危险间隙”。
5. **颅骨外膜**：薄而致密，与颅骨表面连接疏松，仅在骨缝处紧密愈着；骨膜下血肿常局限于一块颅骨范围内，可与腱膜下血肿鉴别；对颅骨有营养和修复作用。

### 颞区（颅顶两侧，层次有别）

由浅入深依次为：皮肤、浅筋膜、颞筋膜（分深浅两层，附着于颧弓）、颞肌（咀嚼肌，扇形，起自颞窝，止于下颌骨冠突）、颅骨外膜；颞区皮肤移动性大，颞肌厚实，常作为开颅手术的入路区域。

### 关键临床要点

1. 头皮 = 皮肤 + 浅筋膜 + 帽状腱膜及额枕肌，三层紧密粘连，手术中常作为一个整体处理。
2. 腱膜下间隙出血 / 感染比骨膜下更危险，易扩散且可能累及颅内。
3. 颅顶血管神经多呈放射状走行于浅筋膜，手术切口宜考虑方向以减少损伤。
