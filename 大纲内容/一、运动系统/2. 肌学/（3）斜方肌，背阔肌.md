# 斜方肌

1. **位置与形态**：斜方肌位于项部和背上部的浅层，呈三角形扁肌，左右两侧合起来呈斜方形。
2. **起止点**：
    - **起点**：以腱膜起于上项线、枕外隆凸、项韧带、第7颈椎棘突以及全部胸椎棘突。
    - **止点**：止于锁骨外侧1/3、肩峰和肩胛冈。
3. **作用**：
    - **对肩胛骨**：可拉肩胛骨向脊柱靠拢，上部肌束能上提肩胛骨，下部肌束能下拉肩胛骨。
    - **对颈部与头部**：若肩胛骨固定，一侧斜方肌收缩可使颈向同侧屈、脸转向对侧；两侧同时收缩可使头后仰。
4. **临床意义**：该肌瘫痪时，会出现“塌肩”现象。

# 背阔肌

1. **基本特征**
    - **形态**：背阔肌是全身最大的扁肌。
    - **位置**：位于背下部及胸后外侧壁 。
2. **起止点**
    - **起点**：以腱膜起自下位6个胸椎棘突、全部腰椎棘突、骶正中嵴、髂嵴后部及下位3个肋骨外面 ，起点广泛。
    - **止点**：止于肱骨小结节嵴。
3. **功能作用**
    - **肩部运动**：收缩时能使肩关节产生后伸、内收及旋内动作。
    - **特殊动作**：当上肢上举固定时，可协助完成引体向上动作。
